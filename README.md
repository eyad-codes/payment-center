🎯 Overview

Payment Center is a lightweight, modern web application designed to streamline the way users view and interact with payment information. Whether you're managing multiple payment providers or simply showcasing a single account, this project delivers a seamless experience with one-click copy functionality and a polished dark UI.

✨ Features

 Feature Description
🌙 Modern Dark UI A sleek, eye-friendly interface designed for clarity
📱 Fully Responsive Optimized for desktop, tablet, and mobile devices
🌍 Arabic RTL Support Full right-to-left layout support for Arabic users
📋 One-Click Copy Instantly copy account numbers or IBANs
🧩 Reusable Components Modular React components for easy maintenance

⚙️ Getting Started

1️⃣ Clone the repository

```bash
git clone <your-repository-url>
```

2️⃣ Navigate to the project

```bash
cd payment-center
```

3️⃣ Install dependencies

```bash
npm install
```

4️⃣ Start the development server

```bash
npm run dev
```

5️⃣ Open in your browser

```
http://localhost:3000
```

---

🚀 Deployment

The project can be deployed easily on platforms such as:

· ▲ Vercel
· 🌐 Netlify

Build for production

```bash
npm run build
```

---

📌 Customization

Payment methods are managed from a single file:

```bash
data/payment-methods.ts
```

You can add, remove, or update payment providers without touching the main page structure — keeping your code clean and maintainable.
